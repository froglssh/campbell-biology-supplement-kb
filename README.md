> **定位聲明**：本知識庫專門依據 **Campbell Biology 13th Edition (2024)** 提煉建置，旨在**精準補充與深化高中生物教學體系（108課綱）**。
>
> ⚠️ **嚴格隔離規範（防止難度污染）**：
> 本知識庫內容包含大學普通生物學之底層生物化學途徑、分子作用級聯、生物物理熱力學、進階數值模型與前沿科研進展。**請嚴格獨立管理，嚴禁直接併入「高中生物知識庫」或直接用於高中段考常態出題**，以免試題難度過度超標、偏離高中生物課綱精神！

## 為什麼需要獨立的「大學普生補充知識庫」？

在高中生物教學與命題實務中，教師常面臨兩難：
1. **教學需要深入理解**：高中課綱常因課時限制而簡化機轉（例如：「ATP 高能磷酸鍵蘊含大量能量？」、「光反應的 NADPH 與 ATP 產量如何精確滿足卡爾文循環？」、「動作電位通道開關的物理狀態門控？」、「腎臟濃縮尿液的逆流倍增如何實現？」）。若教師僅依賴高中教科書，容易產生教學迷思；具備大學普生的深入知識，能讓教師在備課時胸有成竹、精確劃分教學界限。
2. **防範試題難度失控**：若將大學普生資料與高中題庫、教材混編在同一個資料夾或同一個知識檢索庫中，AI 生成試題或教師搜尋時容易「越界混淆」，導致高中段考或學測模考出現非課綱所需的複雜蛋白質亞基、代謝名詞或過深數學推導，重創學生學習信心。

因此，本知識庫遵循**「獨立架構、精準對照、深度解析、防範污染」**四大原則建立。

## 檢索工具使用方法

知識庫內建 `search_campbell_kb.py`，支援多維度極速檢索：

```bash
# 1. 依高中課程關鍵字查詢（例如：光合作用、動作電位、逆流倍增）
python3 search_campbell_kb.py --query "光合作用"

# 2. 依 Campbell 章節查詢（例如：Chapter 9 細胞呼吸）
python3 search_campbell_kb.py --chapter 9

# 3. 依單元主題過濾（例如：Unit 3 遺傳學）
python3 search_campbell_kb.py --unit 3

# 4. 依 108 課綱模組過濾（例如：選修生物I、必修生物）
python3 search_campbell_kb.py --curriculum "選修生物I"
```

## 教師使用指引：如何確保難度不超標？

在設計高一必修或選修生物評量試題時，請參考下表控制「邊界界線」：

| 評量對象 | 課綱標準界線（請停留在高中知識庫） | 大學普生知識庫補充建議（嚴格控管） |
|---|---|---|
| **高一必修生物** | 細胞構造功能名稱、有絲分裂階段、孟德爾第一/二法則大意。 | **嚴禁引入**：電子傳遞鏈複合體、次級傳訊者路徑、轉錄因子組裝。僅供教師備課背景知識。 |
| **高二/高三選修生物** | 呼吸光合大步驟、DNA 複製轉錄轉譯標準流程、動植物器官生理通則。 | 可補充：ATP 合酶旋轉機制示意、氣孔保衛細胞離子流方向、光敏素 $P_r/P_{fr}$ 概念。**不考**複雜生化常數。 |
| **校內資優班 / 奧賽培訓** | 大學普生全書範圍，強調圖表數據分析、實驗假說設計與生物物理化學定量概念。 | 深入全書 56 章機制與 Featured Figures，進行學術論文級別的數據判讀與推論。 |
